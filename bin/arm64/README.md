# Alpine-SSH ARM64 Binaries

Place pre-compiled aarch64 / arm64 static binaries here:
- `alpinessh`
- `ssh-ws`
- `dropbear`
- `dropbearkey`
- `dropbearconvert`
- `scp`
- `dbclient`

If these binaries are not present on an ARM64 system, `install.sh` will automatically compile them via `make static` on the Alpine Linux VPS.
